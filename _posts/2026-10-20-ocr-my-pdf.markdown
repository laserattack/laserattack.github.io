# Установка всякого

`Tesseract` - это универсальный движок оптического распознавания
символов (OCR). Его основная задача - "читать" текст с изображений и
преобразовывать его в текст, который может обрабатывать компьютер

`ocrmypdf` - обёртка над движком `Tesseract`. Она берёт PDF,
распознаёт текст на каждой странице и «подкладывает» невидимый
текстовый слой поверх изображения. В результате файл внешне не
меняется, но текст становится выделяемым и копируемым

надо поставить пакеты всех языков которые планируется распознавать
(которые есть в документе). в моем случае - английский и русский

```
sudo xbps-install tesseract-ocr
sudo xbps-install tesseract-ocr-eng
sudo xbps-install tesseract-ocr-rus
sudo xbps-install python3-ocrmypdf
```

проверка

```
~/Desktop/Учеба/9/АРИБ
[serr@lap]-> tesseract-ocr --list-langs
List of available languages in "/usr/share/tessdata/" (4):
eng
equ
osd
rus
```

# Делаю

```
ocrmypdf -l rus+eng --deskew "Методичка АРИБ.pdf" metoda.pdf
```

через `+` в флаге `-l` указываются все языки, которые необходимо
распознавать
