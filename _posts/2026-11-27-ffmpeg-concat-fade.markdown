если нужно собрать несколько видео в один ролик и добавить плавное
появление и затухание каждого фрагмента, можно сделать так

запускаю из папки с исходными видео:

```sh
(
  export LC_ALL=C
  set -e

  : > list.txt

  n=0

  for f in *.mov; do
    n=$((n+1))

    d=$(ffprobe -v error \
      -show_entries format=duration \
      -of csv=p=0 "$f")

    t=$(awk -v d="$d" 'BEGIN {printf "%.6f", d-1}')

    ffmpeg -y -i "$f" \
      -vf "fade=t=in:st=0:d=1,fade=t=out:st=$t:d=1" \
      -c:v libx264 -crf 0 -preset fast \
      -c:a copy \
      "part_$n.mp4"

    printf "file 'part_%s.mp4'\n" "$n" >> list.txt
  done

  ffmpeg -f concat -safe 0 -i list.txt \
    -c copy final.mp4
)
```

`ffprobe` получает длительность очередного файла в секундах.
Затем `awk` вычитает секунду — в этот момент должно начаться
затухание. Например, для ролика длиной 15 секунд получится `14.000000`

в фильтре `fade`:

- `t=in:st=0:d=1` — появление из чёрного с начала ролика за секунду
- `t=out:st=$t:d=1` — затухание до чёрного за последнюю секунду

между фрагментами получается переход через чёрный. Сами фрагменты
идут последовательно, без наложения друг на друга

каждый обработанный ролик сохраняется в `part_1.mp4`, `part_2.mp4`
и так далее. Их имена записываются в `list.txt`, после чего последняя
команда собирает `final.mp4`. На этом этапе `-c copy` копирует потоки
без повторного кодирования

ещё несколько параметров:

- `LC_ALL=C` — фиксирует локаль, чтобы дробная часть числа отделялась точкой
- `set -e` — останавливает выполнение при ошибке команды
- `: > list.txt` — создаёт или очищает список частей перед запуском
- `-c:v libx264` — кодирует видео в H.264
- `-crf 0` — режим кодирования без потерь, файлы получаются большими
- `-preset fast` — задаёт скорость работы кодировщика
- `-c:a copy` — копирует звук без изменений, затухание применяется только к видео
- `-y` — разрешает перезаписывать промежуточные `part_*.mp4`

для меньшего размера вместо `-crf 0` можно использовать `-crf 18`,
если допустимо сжатие с потерями

исходники нужно заранее назвать в нужном порядке, например
`001.mov`, `002.mov`, `003.mov`: цикл перебирает файлы по именам.
В папке должен быть хотя бы один `.mov`

этот вариант рассчитан на клипы с одинаковыми параметрами потоков:
разрешением, частотой кадров, наличием и параметрами звука.
Скрипт их не выравнивает, а склейка через `-c copy` требует
совместимых частей. Исходный аудиокодек также должен поддерживаться
контейнером MP4

для непересекающихся секундных появления и затухания длина каждого
клипа должна быть хотя бы две секунды
