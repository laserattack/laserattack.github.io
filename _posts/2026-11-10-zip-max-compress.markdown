у меня есть папка на 4.4гб

```
du -sh курсач/
4,4G	курсач/
```

она состоит из максимально разных файлов, там есть и текстовые файлы и
диск виртуальной машины `colima` и снапшоты `restic`, разные кэши,
картинки, отчеты и тд

сжимать хочу используя `zip`, чтобы на любой платформе можно было
распаковать без трудностей

максимальное сжатие так

```
zip -r -9 курсач.zip курсач
```

где

- `-r` — рекурсивно архивирует папку со всем содержимым
- `-9` — максимальный уровень сжатия ZIP (от 0 до 9)
- `курсач.zip` — имя итогового архива
- `курсач` — папка, которую сжимаем

в итоге получился архив 2.6гб

```
~/Desktop/study/9/БИВ
[serr@mac]-> du -sh курсач.zip
2,6G	курсач.zip
```
