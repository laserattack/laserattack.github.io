# **CR+LF - Carriage Return + Line Feed (Windows/DOS)**

- **Формат**: `\r\n` (Carriage Return + Line Feed)
- **Происхождение**:
	- `\r` (CR, ASCII 13) - возврат каретки в начало строки (как в печатных машинках)
	- `\n` (LF, ASCII 10) - перевод на новую строку

# **LF - Line Feed (Unix/Linux/macOS)**

- **Формат**: `\n` (только Line Feed)
- **Философия**:
    - Минимализм (один символ вместо двух)
    - В Unix `\n` подразумевает и возврат каретки, и новую строку

# Зачем это знание?

Если, например, скрипт `bash` был отредактирован в Windows (например,
в Блокноте или некоторых IDE), он может содержать `CR+LF`, что
приведёт к ошибке при запуске в Unix-системе. Фиксится так:

```
sed -i 's/\r$//' example.sh
```
