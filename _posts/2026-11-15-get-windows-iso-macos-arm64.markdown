# Проблема

Понадобилось установить Windows 11 в виртуальную машину на Mac с
процессором Apple Silicon (M4). Для этого нужен установочный ISO-образ
**Windows 11 ARM64**, поскольку обычная x64-версия Windows не подходит
для нативной виртуализации на Apple Silicon.

Казалось бы, достаточно зайти на официальный сайт Microsoft и скачать
ISO, но при попытке загрузки появилась ошибка:

```text
We are unable to complete your request at this time.
Some users, entities and locations are banned from using this service.

Error code: 715-123130
```

Microsoft ограничивает доступ к загрузке для некоторых IP-адресов,
регионов и сетевых конфигураций. При этом ошибка может появляться даже
без использования VPN.

В результате скачать официальный ISO привычным способом не удалось.

# Решение

Нашёл утилиту **CrystalFetch** — бесплатное приложение с открытым
исходным кодом для macOS, позволяющее скачивать установочные файлы
Windows и собирать из них ISO-образ.

CrystalFetch использует UUP Dump и получает компоненты Windows с
серверов Microsoft. То есть это не сторонняя модифицированная сборка
Windows, а способ самостоятельно сформировать установочный ISO из
оригинальных компонентов.

Проект: https://github.com/TuringSoftware/CrystalFetch

## Установка через Homebrew

CrystalFetch доступен в Homebrew, поэтому установка занимает одну
команду:

```bash
brew install --cask crystalfetch
```

После установки запускаем:

```bash
open -a CrystalFetch
```

## Выбор версии Windows

В CrystalFetch выставил следующие параметры:

- **Version:** Windows 11
- **Build:** Latest
- **Architecture:** Apple Silicon
- **Language:** Russian (Russia)
- **Edition:** Windows 11

Архитектура Apple Silicon соответствует ARM64 — именно такая Windows
нужна для виртуализации на Mac M-серии.

## Загрузка ISO

После выбора параметров запустил скачивание.

CrystalFetch начал загружать установочные компоненты Windows 11
ARM64. В моём случае загрузка началась с файла:

```text
26100.4349.250607-1500.ge_release_svc_refresh_CLIENTCONSUMER_RET_A64FRE_ru-ru.esd
```

Размер загружаемого файла составил примерно **4,49 ГБ**.

В отличие от прямой загрузки через сайт Microsoft, процесс успешно
стартовал, и ошибка 715-123130 больше не препятствовала получению
файлов.

После скачивания CrystalFetch должен подготовить ISO-образ.

# Почему это работает?

CrystalFetch использует другой механизм получения дистрибутива Windows.

Вместо скачивания готового ISO с веб-страницы Microsoft программа
получает установочные компоненты через инфраструктуру обновлений
Windows (UUP) и формирует ISO локально.

Таким образом, удаётся избежать конкретной проблемы с выдачей ссылки на ISO на сайте Microsoft.

Стоит учитывать, что это не универсальный обход географических
ограничений: если сеть блокирует доступ и к серверам загрузки
компонентов, CrystalFetch тоже может не сработать.

# Итог

Если официальный сайт Microsoft выдаёт ошибку **715-123130** при
скачивании Windows 11 ARM64, можно попробовать CrystalFetch.

Преимущества способа:

- Не требуется искать ISO на сторонних файлообменниках.
- Используются установочные компоненты Microsoft.
- Поддерживается архитектура ARM64 для Apple Silicon.
- Утилита бесплатная и устанавливается через Homebrew.
- Можно выбрать нужный язык Windows.

В моём случае CrystalFetch успешно начал скачивание Windows 11 ARM64,
несмотря на блокировку загрузки через официальный сайт Microsoft.

**Важно:** получение ISO не заменяет лицензию Windows. Для активации
системы потребуется действующая лицензия.
