# Создание мастерключей

Мастерключи должны храниться только в зашифрованной ФС, я буду
использовать `gocryptfs` - оверлейную зашифрованную файловую систему

```
mkdir ~/mnt/gocryptfs/pgp-keys
```

# Экспорт субключей в основную систему

мастерключ не экспортируется, он живет только в зашифрованной фс, это ключевое требование


# Сохранение приватных мастерключей в keepass

**Публичный ключ математически выводим из приватного**

```
gpg --homedir ~/mnt/gocryptfs/pgp-keys --export-secret-keys "Primary Key (Clean)" > /tmp/primary-clean-secret.asc
```

и в keepassxc например аттачментсы добавляются в заметке во вкладке
`Advanced`

оттуда же их можно сохранить в систему

импорт из `.asc` так

```
~
[serr@lap]-> mkdir -p /tmp/test-gpg && chmod 700 /tmp/test-gpg
~
[serr@lap]-> gpg --homedir /tmp/test-gpg --import /tmp/primary-clean-secret.asc
gpg: keybox '/tmp/test-gpg/pubring.kbx' created
```
