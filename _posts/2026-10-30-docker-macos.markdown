# Отличие от Linux

Поскольку **напрямую запустить Linux-контейнеры на macOS невозможно**,
все инструменты используют один и тот же трюк: они запускают скрытую,
очень лёгкую виртуальную машину с Linux.

Внутри этой виртуальной машины уже работает полноценный
Docker-движок. А когда вы вводите команду `docker run` в терминале
Mac, она просто передаёт эту команду внутрь виртуалки.

`Colima` — это просто инструмент, который управляет такой виртуалкой.

# Делаю

установка `Colima`

```
brew install colima docker
```

и запуск

```
colima start
```

и проверка работы запуском контейнера

```
docker run hello-world
```

по окончании работы с докером `Colima` надо выключить

```
colima stop
```
